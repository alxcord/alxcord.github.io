# Modelos

O modelo é uma etiqueta pronta que serve de base para outras. Use quando várias etiquetas têm o mesmo desenho e mudam só em um ou dois campos, como o nome do alimento e o peso.

Os modelos não entram no limite de etiquetas da versão gratuita.

## Criar um modelo

1. Na tela inicial, abra a pasta **Modelos**, a primeira da lista.
2. Toque em **Novo modelo** e monte a etiqueta como qualquer outra.
3. Na janela de um texto ou de uma quantidade, marque **Preencher ao usar o modelo** nos campos que mudam a cada etiqueta. Eles aparecem na lista com ✎.
4. Salve.

Outro caminho: abra uma etiqueta que já existe e toque em **Salvar como modelo**.

## Usar um modelo

Toque em **Novo item**. Com modelos cadastrados, o app pergunta se a etiqueta começa em branco ou a partir de um modelo.

Escolhido o modelo, uma janela pede o nome da etiqueta e um valor para cada campo marcado. Ao confirmar, o formulário abre com a etiqueta pronta. Escolha o grupo e salve.

## Duplicar

Para uma etiqueta parecida com outra, sem passar por modelo, use **Duplicar** no menu ⋮ da etiqueta no grupo ou no fim do formulário.
