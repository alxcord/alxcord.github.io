# Backup e planilha

O Imprinta tem duas formas de tirar o catálogo do celular. O backup leva tudo, com as fotos. A planilha CSV leva só os dados das etiquetas, para editar no computador.

## Backup do catálogo

Em **Configurações**, na seção **Backup do catálogo**:

- **Exportar** gera um arquivo `.zip` com etiquetas, grupos, modelos e fotos. Guarde onde quiser.
- **Importar** restaura um arquivo exportado antes.

> Importar um backup substitui o catálogo atual. O app pede confirmação antes. Se tiver dúvida, exporte o catálogo atual primeiro.

Para trocar de celular, exporte no aparelho antigo, copie o `.zip` para o novo e importe.

## Planilha CSV

A planilha tem uma etiqueta por linha. Use para cadastrar muitas etiquetas de uma vez ou corrigir vários itens no Excel ou no Google Planilhas.

1. Em **Configurações**, toque em **Exportar planilha (CSV)**.
2. Abra o arquivo no computador, edite e salve como CSV.
3. De volta ao app, toque em **Importar planilha (CSV)**.

A importação acrescenta etiquetas novas e atualiza as que já existem, sem apagar nenhuma. Linhas sem nome são ignoradas. No fim, o app mostra quantas etiquetas criou e quantas atualizou.

As fotos não vão na planilha. Para levar as fotos, use o backup.
